## Tema escolhido
Lista de tarefas

## Descrição do projeto
A página permite cadastrar tarefas com prioridade.
O usuário preenche os campos do formulário e o JavaScript valida as informações.
Se os dados estiverem corretos, a tarefa é adicionada na lista exibida na tela.

## Como executar
1. Baixe os arquivos do projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo index.html no navegador.
